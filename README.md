# SlackChrome

**SlackChrome** is the first-ever "slackline" inspired theme for Google Chrome. Designed with a professional and focused aesthetic, it uses a calming palette of slate and sky blues to provide a clean, distraction-free browsing experience.

## 🌟 Features

* **Custom Color Palette:** * **Frame:** Deep Slate Blue `[65, 111, 148]`
* **Toolbar:** Soft Sky Blue `[161, 195, 235]`
* **NTP Background:** Matching serene blue tones `[163, 195, 236]`


* **Optimized Visibility:** High-contrast black text for tabs and bookmarks, with white text for background tabs.
* **Custom NTP Assets:** Includes `slackchrome.png` for the New Tab Page and a custom attribution logo.
* **Modern Standards:** Built using **Manifest V3**.

## 🛠 Installation

Since this is a custom theme, you can load it manually into your browser:

1. **Download** or clone this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle in the top right corner.
4. Click the **Load unpacked** button.
5. Select the folder containing the `manifest.json` file.

## 🏗 Development & Customization

If you want to modify the colors or images for your own version:

1. **Colors:** Open `manifest.json` and edit the RGB values under the `"colors"` object.
2. **Images:** Replace `slackchrome.png` or `credits.png` with your own images (ensure the filenames match or update them in the manifest).
3. **Testing:** After making changes, go back to `chrome://extensions/` and click the **Reload** icon on the SlackChrome card.
